# Phase 3D manual acceptance checklist

**Status:** Prepared; actual staff usability testing pending  
**Purpose:** Verify the synthetic applicant submission, intake, correction, and resubmission journey without making an official decision.

## Applicant tasks

- [ ] Sign in as a verified synthetic SCHOOL user.
- [ ] Select the correct represented synthetic organization.
- [ ] Start or resume one test application.
- [ ] Complete applicable questionnaire answers and documentary evidence links.
- [ ] Check progress and correct any missing items.
- [ ] Submit the test application and identify its current state.
- [ ] Confirm the submitted working revision cannot be edited.
- [ ] After a correction request, understand the summary and open the new working revision.
- [ ] Save corrections, leave, resume, and resubmit.
- [ ] Confirm earlier submission history remains visible.

## CHEDRO tasks

- [ ] Sign in as an assigned synthetic CHEDRO reviewer.
- [ ] Find **Application intake** without assistance.
- [ ] Open an application assigned to the exact region and module.
- [ ] Identify the persistent nonofficial test notice.
- [ ] Start screening.
- [ ] View applicable answers and exact submitted documents.
- [ ] Request one question, document, or general correction in plain language.
- [ ] Confirm no official approval, rejection, validation, certificate, or issuance action exists.

## Security checks

- [ ] Another SCHOOL account cannot open the application or working revision.
- [ ] An unassigned CHEDRO account cannot open the intake record.
- [ ] A reviewer assigned to another region or module cannot open it.
- [ ] Revoking the reviewer assignment blocks the next request immediately.
- [ ] Retiring the manifest keeps history readable and blocks further correction/resubmission.

## Observation record

Record task completion, elapsed time, navigation mistakes, unclear wording, assistance required, keyboard/focus issues, viewport/theme used, and suggested improvements. Do not mark staff usability testing complete until real participants have performed this script.
