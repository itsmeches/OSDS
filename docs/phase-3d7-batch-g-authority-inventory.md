- **C - Covered by implementation but not independently verified:** a transaction/audit implementation is visible; success/authorization evidence may exist, but its mandatory-audit failure/concurrency boundary has not been independently demonstrated in the reviewed evidence.

**FI** below means proposed audit-sink failure injection. **Existing** means no additional FI is needed for that accepted operation absent a concrete regression. **Proposed** is a coverage gap, not new permission to run tests or an invented release requirement. **Contract first** means a mandatory event must be established before an audit-failure test is meaningful.
