## Tasks

1. Sign in as an authorized synthetic OSDS user.
2. Open **Questionnaires** and identify the current state and next action.
3. Use **Create questionnaire**, select an existing approved service, and create an initial synthetic draft.
4. Open ACSA and select **Continue editing**.
5. Locate **Organization type** in the outline.
6. Change its title and required state.
7. Select another question and return; verify the unsaved edit remains.
8. Add a multiple-choice question and add choices.
9. Move the new question, duplicate it, then delete the duplicate.
10. Open Preview, enable Test as applicant, and test a conditional answer.
11. Close Preview and confirm the unsaved editor values remain.
12. Save the draft, leave the page, and resume it.
13. Open **Required documents**, edit a requirement, change stages, and return.
14. Open **Review and test** and run **Check configuration**.
15. Use each reported issue link and correct the problem.
16. Open **Send for approval** and send the exact saved pair for Admin review.
